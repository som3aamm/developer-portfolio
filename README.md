# Ismail | Software Engineer Portfolio

> A production-oriented, responsive static website concept built with semantic HTML, modern CSS and vanilla JavaScript. **Portfolio concept / fictional presentation**, not a claim of a commissioned client website.

## Features

- Responsive layout for phone, tablet and desktop
- Accessible navigation, functional buttons and interactive components
- SEO metadata, favicon, no build step and no backend dependency
- Designed to work directly on **GitHub Pages**

## Live preview

After publishing, your URL will normally be:

`https://YOUR-USERNAME.github.io/developer-portfolio/`

## Run locally

Open `index.html`, or use a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish on GitHub Pages

1. Create a **public** repository named `developer-portfolio`.
2. Upload **the contents of this folder** (not the outer folder). Keep `index.html` in the repository root.
3. Commit the files.
4. Visit **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, `main`, `/ (root)`, then save.
5. Open `https://YOUR-USERNAME.github.io/developer-portfolio/` after deployment.

## Before using for a real business

Replace editorial images (currently loaded from Unsplash CDN), company name, marketing copy, brand links, legal details, prices, contact addresses and any placeholder social channels with verified assets and authorized contact data. Images require internet access; CSS color/gradient fallback remains visible offline. No fake customer reviews, unverified metrics, or simulated completed orders are included.

This is a **real functioning static website**, but cannot truthfully represent a real company's official website or accept real payments/bookings without that company's data and back-end services.
